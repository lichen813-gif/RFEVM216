# Reference Examples

Reference applications are stored in the repository's [`examples/`](https://github.com/lichen813-gif/RFEVM216/tree/main/examples) directory rather than inside the documentation tree.

Each example should contain:

- a dedicated `README.md`;
- supported board and hardware revision;
- Vivado, Vitis, or other tool versions;
- build and programming steps;
- runtime instructions and expected output;
- known limitations and required external equipment;
- a clear license or reuse statement for third-party content.

No reference programs have been added yet.
